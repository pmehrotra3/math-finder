What's next

All fourteen milestones are built and verified. PROGRESS.md has the full log, including every verification command and its output. Ideas for going further, each a project of its own:

  • Harder benchmark: add real miniF2F problems to bench/problems.jsonl. The current set is solved 20/20, so it can no longer show improvement.
  • Faster Lean: keep Mathlib loaded in a persistent Lean process (the Lean REPL) instead of starting Lean for every batch. Most of the time spent is loading Mathlib.
  • Use your trained model: serve the LoRA adapter from M13 and add it as a third backend in llm.BACKENDS.
  • A value model in the search: train a classifier on value.jsonl and use it to order plans, instead of "fewest lemmas first".
