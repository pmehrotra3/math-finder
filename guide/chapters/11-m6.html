M6: Explaining the proof in plain mathematics

What and why. A Lean proof is certain but hard to read. Once Lean has checked it, we ask Claude to write it up the way a textbook would: the theorem, the key idea, then one step per lemma. Every step is tagged with its Lean name, like (`mod_six_cases`), so you can always trace a sentence back to the exact part of the formal proof it describes. The explainer can't make the proof wrong, because the proof is already verified. Its only job is to be clear and honest, so the prompt tells it to describe only what the Lean proof actually does. Every proved theorem is also saved to disk: the exact Lean file (which you can check again any time) and the explanation.

Checkpoint

After the verified Lean proof, we got (about 1½ minutes in total; your wording will differ):

Writing the explanation...

## Theorem
For every integer $n$,
$$6 \mid n^3 - n.$$

## Idea
Divisibility by $6$ means the remainder modulo $6$ is $0$. The remainder of $n^3 - n$ modulo $6$ depends only
on the remainder $r$ of $n$ modulo $6$. So it suffices to check the six possible values $r = 0, 1, \dots, 5$.

## Proof

1. **Step 1** (`mod_six_cases`). For every integer $n$, the remainder $n \bmod 6$ is one of $0, 1, 2, 3, 4, 5$.
   ...
2. **Conclusion** (`main`). The proof first rewrites the goal $6 \mid n^3 - n$ into ... $(n^3 - n) \bmod 6 = 0$ ...
   | $r$ | $r^3 - r$ | $\bmod 6$ |
   ...

Common errors

  • The explanation prints but Saved to never appears: an exception happened in save_run. Check you can write to the project folder.
  • Math shows as raw $...$: that's expected in the terminal. The website (M10) renders it, and any Markdown viewer with math support shows it nicely.
  • Tests create folders in your real runs/: a test is missing monkeypatch.setattr(cli, "RUNS_DIR", tmp_path).
