Chapter 0: Prerequisites

What and why. You need three things: Lean (the proof checker), Mathlib (Lean's huge library of already-proved math), and Python tooling to run the search engine. You also need a way to talk to Claude: either the claude command line tool or an API key.

  1. Install Homebrew (the Mac package manager) if brew --version doesn't print a version. Follow the one-line install on brew.sh, then open a new terminal.

    brew --version

  2. Install elan, the Lean version manager. It downloads the right Lean version for each project automatically.

    brew install elan-init

    This gives you three commands: elan (manages Lean versions), lean (the checker) and lake (Lean's build tool, like npm or cargo).

  3. Install uv, a fast Python project manager.

    brew install uv

    uv creates an isolated Python environment (.venv) per project and installs packages into it, so this project can't break your other Python code.

  4. Make sure you can talk to Claude. Option A: the Claude Code CLI (uses your Claude subscription, no key needed):

    claude --version

    Option B: an API key from platform.claude.com, set in your terminal only (never in a file you share):

    export ANTHROPIC_API_KEY="sk-ant-..."

  5. Create the project folder and go into it.

    mkdir -p ~/Desktop/math_proofs
cd ~/Desktop/math_proofs

  6. Create a Lean project that uses Mathlib. The +leanprover-community/mathlib4:lean-toolchain part means "use the Lean version Mathlib currently needs".

    lake +leanprover-community/mathlib4:lean-toolchain new lean_env math

    This creates lean_env/ with lakefile.toml (declares the Mathlib dependency) and lean-toolchain (pins the Lean version, here v4.36.0-rc2).

  7. Download Mathlib's prebuilt files. Compiling Mathlib yourself takes hours; this downloads it (several GB) instead.

    cd lean_env
lake exe cache get
cd ..

  8. Create the empty folders the project will fill in.

    mkdir -p mathfinder tests server web guide/chapters tools

Checkpoint

Prove something real. Create a scratch file and check it:

cd lean_env
mkdir -p .mf_tmp
printf 'import Mathlib\n\nexample (a b : ℝ) : a ^ 2 + b ^ 2 ≥ 2 * a * b := by\n  nlinarith [sq_nonneg (a - b)]\n\n#eval 2 + 2\n' > .mf_tmp/hello.lean
lake env lean --json .mf_tmp/hello.lean
cd ..

You should see exactly one message, the output of #eval, and no errors:

{"caption":"","data":"4", ... "severity":"information"}

What happened: example ... := by nlinarith [sq_nonneg (a - b)] states a² + b² ≥ 2ab for real numbers and proves it. The hint sq_nonneg (a - b) says "(a−b)² ≥ 0", and nlinarith (nonlinear arithmetic) finishes it. No output about the theorem means Lean accepted the proof. --json makes Lean print messages as JSON, which our Python code will read in M1.

The first run can take a minute or more while your Mac loads Mathlib from disk. Later runs take about 20 seconds.

Common errors

  • unknown module prefix 'Mathlib': you're not inside lean_env, or you ran lean instead of lake env lean.
  • It takes many minutes and your CPU is at 100%: the cache download didn't finish and Lean is compiling Mathlib. Stop it (Ctrl-C) and rerun lake exe cache get.
  • command not found: lake: open a new terminal after brew install elan-init.
